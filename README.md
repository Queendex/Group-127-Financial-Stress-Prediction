Group 127 – Financial Stress Prediction

About the Project

Welcome to Group 127’s Financial Stress Prediction project!

We are a team of 50 members working together on a Data Science and Machine Learning capstone project. Our goal is to develop a machine learning model that can identify customers who may experience financial stress within the next 30 days.

Project Overview

The project will use six months of mobile money transaction history to study customer transaction patterns and identify possible signs of financial difficulty.

We aim to:

* Explore and understand transaction data.
* Clean and prepare datasets for analysis.
* Identify patterns and indicators of financial stress.
* Build and evaluate machine learning models.
* Develop a model that can predict potential financial stress in the next 30 days.

Team Collaboration

All members will contribute to the project through smaller working groups. Each group will handle specific tasks, share progress, and collaborate with other members.

We will use GitHub to:

* Share and manage project files.
* Track changes to our work.
* Collaborate on code and documentation.
* Review contributions and improve our work together.

Project Structure

* data/ – Approved datasets and processed data.
* notebooks/ – Data exploration and experiments.
* src/ – Python scripts and model development.
* docs/ – Project documentation.

Our Goal

To build a reliable and useful machine learning solution while learning, sharing ideas, and growing together as a team.
